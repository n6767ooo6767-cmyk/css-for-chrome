# Neon Night CSS 🌙

A small Chrome extension that applies a neon-dark visual style to websites.

## Files

- `manifest.json` — Chrome Extension Manifest V3 configuration
- `style.css` — the theme styles

## Install locally

1. Open Chrome.
2. Go to `chrome://extensions`.
3. Turn on **Developer mode**.
4. Click **Load unpacked**.
5. Select this project folder.
6. Open a website and refresh the page.

## Notes

This is a browser extension, not a Chrome Web Store theme. It changes website content with CSS and does not change Chrome's own toolbar or browser controls.

Some websites may use their own styles that override parts of the theme.
